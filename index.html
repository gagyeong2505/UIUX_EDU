FAQ

수강 전 자주 묻는 질문

UIUX 과정 상담 시 자주 확인하는 내용을 정리했습니다. 과정 선택과 학습 범위를 이해하는 참고 자료로 활용할 수 있습니다.

Q01 UIUX를 처음 배우는 비전공자도 수강할 수 있나요?
A

네, 가능합니다. UIUX 관련 경험이 없는 비전공자도 수강할 수 있도록 기초 개념부터 단계적으로 진행합니다.

Q02 UIUX1, UIUX2, UIUX3는 꼭 순서대로 들어야 하나요?
A

반드시 순서대로 수강할 필요는 없습니다. 다만 Figma 사용 경험이 없거나 기초가 부족한 경우에는 UIUX1부터 순서대로 수강하는 것을 권장합니다.

Q03 Figma를 한 번도 사용해본 적이 없어도 괜찮나요?
A

네, 괜찮습니다. UIUX1 과정에서 Figma의 기본 툴 조작부터 Auto Layout, Component, Variable 등 기초 기능을 순차적으로 학습합니다.

Q04 UIUX2에서는 어떤 결과물을 만들게 되나요?
A

서비스 기획과 앱 디자인을 위한 전반적인 초안 작업을 진행합니다. IA, User Flow와 같은 서비스 구조 설계뿐 아니라 로고, 아이콘 등 앱 디자인 제작에 필요한 기본 에셋까지 준비할 수 있습니다.

Q05 UIUX2와 UIUX3에서는 AI를 어떻게 활용하나요?
A

AI를 활용해 시장조사, 경쟁 서비스 조사, 서비스 기획 등의 초안을 제작합니다. 이후 수강생의 아이디어와 의견을 더해 내용을 보완하고 기획을 고도화하는 방식으로 활용합니다.

Q06 앱 디자인과 웹 디자인을 모두 배우나요?
A

네, 모두 학습합니다. 모바일 앱 UI 디자인과 웹 UI 디자인뿐 아니라 반응형 웹 디자인의 기본 설계 방법까지 함께 배웁니다.

Q07 수업에서 개인 포트폴리오까지 완성할 수 있나요?
A

포트폴리오 전체를 완성하는 과정은 아닙니다. 대신 개인 포트폴리오를 제작할 때 필요한 구성 방법, 작업 순서, 프로젝트 정리 방법 등을 학습할 수 있습니다.

Q08 기존 앱이나 웹사이트를 리디자인하는 수업도 진행하나요?
A

네, 진행합니다. 기존 서비스의 컨셉과 브랜드 방향은 유지하면서 사용성, 정보 구조, 레이아웃 등을 분석하고 개선하는 리디자인 실습을 진행합니다.

Q09 코딩도 함께 배우나요?
A

코딩 수업은 진행하지 않습니다. HTML, CSS 등의 개발보다는 UI 디자인, 화면 설계, 서비스 기획, 반응형 구조 설계에 중점을 둡니다.

Q10 전체 과정을 수강하면 어느 정도의 결과물을 만들 수 있나요?
A

서비스 기획부터 앱·웹 디자인까지 전반적인 초안 작업을 진행할 수 있습니다. 시장조사, IA, User Flow, Wireframe, 디자인 에셋, UI 디자인 등 실제 프로젝트를 시작하고 발전시키기 위한 기본 구조를 스스로 제작할 수 있는 수준을 목표로 합니다.

EDUCATION GOAL

기획할 수 있고,
구조를 설계하며,
직접 완성하는 디자이너

UIUX 교육의 최종 목표는 단순한 툴 사용자가 아니라 사용자 문제를 이해하고 서비스 구조를 설계하며 실제 인터페이스까지 완성할 수 있는 디자이너로 성장하는 것입니다. AI는 이 과정에서 속도를 높이는 보조 도구로 활용하고, 최종 판단과 완성은 디자이너의 역할로 남겨둡니다.
